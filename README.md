# Campus Maintenance Requests API (ICT251 Activity 7)
Student: Maxine Muchinda | Student No: 202508546

Local run:
1. Install Node.js LTS and PostgreSQL; create an empty database called `maintenance`.
2. `npm install`
3. Copy `.env.example` to `.env` and set DATABASE_URL.
4. `npm run setup` (creates the table and inserts the starting records once)
5. `npm start`, then open http://localhost:3000
